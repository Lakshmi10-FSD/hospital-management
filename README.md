# 🏥 Hospital Appointment Booking System

A simple and responsive web application to **book, view, and manage doctor appointments**. Built using **HTML, Tailwind CSS, and JavaScript**, with data stored in the browser using **LocalStorage**.

---

## 🚀 Features

* 📅 Book doctor appointments
* 📋 View all appointments
* ❌ Delete appointments
* 📱 Responsive design (Mobile + Desktop)
* 💾 Data stored using LocalStorage

---

## 🛠️ Tech Stack

* HTML
* Tailwind CSS
* JavaScript

---

## 📂 Project Structure

```
index.html
book.html
appointments.html
```

---

## ▶️ How to Use

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
4. Book and manage appointments
